# COMP3074 LabEx4 — Customer Directory

Student: Ethan Hakaj  
Student number: 101465282

This Android app stores customers locally in a Room database backed by SQLite. The `customers` table contains `id`, `name`, `age`, and `isActive`. The screen lists saved customers, validates and adds new customers, and removes them by ID.

## Run

Open this folder in Android Studio and run the `app` configuration on an emulator or Android device. It uses Gradle and the Android Gradle Plugin versions in the project files. The debug APK is available at `app/build/outputs/apk/debug/app-debug.apk` after building.
